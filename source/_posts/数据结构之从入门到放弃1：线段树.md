## $Description$

已知一个数列，你需要进行下面两种操作：

1.将某区间每一个数加上$x$

2.求出某区间每一个数的和

## $Solution$

首先，线段树的原理是什么？

![](https://p1.ssl.qhimg.com/dr/270_500_/t019962d43ac8e17481.png?size=715x480)

如上图，这就是一颗线段树，

在每个节点，都存储原数组a的一段区间

可以看出，除了树的最后一层，这是一颗完全二叉树，深度是 log N

因此，我们可以使用如下的父子关系表示方法：

1.根节点的编号为1

2.编号为x的节点的左子点编号是x  *2,右子节点的编号是x*  2 + 1，父亲是x / 2

我们需要开一个struct来存储

```
struct T{
	int l, r, ？(sum);
}tree[N];
```

l表示该节点代表区间的左端点，r表示区间的右端点，？是你要实现的功能需要的值，在本题里应为sum，代表该区间的和

这棵树最多应该会有N + N/2 + N/4 +… + 2 + 1 = 2N-1 个节点

还要再加上最后一层的2N个，所以

#### 线段树的数组长度要不小于4N

上述代码的N应改为4 * N

### 建树

线段树的基本用途是对一个序列进行维护（查询或修改）

二叉树可以很方便的传递消息，显然有

sum(x) = sum(x  *2) + sum (x*  2 + 1)

下面的代码很好理解：  
```
struct T{
	int l, r, sum;
	#define l(x) tree[x].l
	#define r(x) tree[x].r
	#define sum(x) tree[x].sum //这样用起来方便直观一点，个人习惯吧
}tree[100005 * 4]; 

void build(int w, int l, int r){
	l(w) = l; r(w) = r;
	if(l == r){sum(w) = a[l]; return;}
	int mid = (l + r) / 2;
	build(w * 2, l, mid);
	build(w * 2 + 1, mid + 1, r);
	sum(w) = sum(w * 2) + sum(w * 2 + 1); 
}

int main(){
	build(1, 1, n);
}
```

### 单点修改

在线段树中，修改一个点，意味着修改最后一层的一个点

它的所有祖先的值都会被修改，于是我们就从根节点向下遍历，找到这个节点所在的位置，并更新沿途经过节点的值  
```
void change(int w, int x, int v){
	if(l(w) == r(w)){t[w].sum = v; return;}
	int mid = (l(w) + r(w)) / 2; //当前节点表示的区域中点
	if(x <= mid) change(w * 2, x, v);  //在左半区间
	else change(w * 2 + 1, x, v); //在右半区间
	sum(w) = sum(w * 2) + sum(w * 2 + 1);
}
```

### 区间查询

对于一个需要查询的区间l，r

我们只需要从根节点开始，递归执行以下操作：

1.如果该节点代表的区间被l，r完全覆盖了，立即返回该节点的sum值

2.如果该节点的左节点与l，r有重叠，递归访问左子节点

3.如果该节点的右节点与l，r有重叠，递归访问右子节点  
```
int query(int w, int l, int r){
	if(l <= l(w) && r(w) <= r) return sum(w); //完全包含
	int mid = (l(w) + r(w)) / 2;
	int val = 0;
	if(l <= mid) val += query(w * 2, l, r);  //左子节点有重合
	if(mid < r) val += query(w * 2 + 1, l, r); //右子节点有重合
	return val;
}
```

### 区间修改

如果像单点修改那样，要从根往底遍历每个点的话，时间复杂度将会达到O(N)，这是不可能的

试想：如果你把一个区间的每一个数都修改了一遍，在之后的查询里却根本没有用上，这次修改等于白白浪费时间

那么我们可不可以，像区间查询一样，遇到完全包含的就立即返回咧？

答案是可以。只不过我们要给这个节点w增加一个标记，表示：这个节点包含的区域被加上了q，但是我没有对它的子节点进行修改

如果在之后的查询中，需要从节点w向下递归，我们就把w的标记去掉，并且给它的两个子节点都打上标记

这样一来，修改操作就变成在区间查询的操作里同步完成了，时间复杂度也下降到了logN

我们在struct里面再加一个变量：add，表示该节点表示的区域要加几并且还没有执行

```
void spread(int p){
	if(add(p)){
		sum(p * 2) += add(p) * (r(p * 2) - l(p * 2) + 1);
		sum(p * 2 + 1) += add(p) * (r(p * 2 + 1) - l (p * 2 + 1) + 1);
		//子节点的和要加上add(p) * 子段长度
		add(p * 2) += add(p);
		add(p * 2 + 1) += add(p);
		//给子节点打上标记
		add(p) = 0;
		//清楚该节点的标记
	}
}
```

## $Code$

```
#include <bits/stdc++.h>
#define int long long
using namespace std;

int n, m, a[100005], op, l, r, d;
struct T{
	int l, r, sum, add;
	#define l(x) tree[x].l
	#define r(x) tree[x].r
	#define sum(x) tree[x].sum
	#define add(x) tree[x].add
}tree[100005 * 4]; 

void build(int w, int l, int r){
	l(w) = l; r(w) = r;
	if(l == r){sum(w) = a[l]; return;}
	int mid = (l + r) / 2;
	build(w * 2, l, mid);
	build(w * 2 + 1, mid + 1, r);
	sum(w) = sum(w * 2) + sum(w * 2 + 1); 
}

void spread(int p){
	if(add(p)){
		sum(p * 2) += add(p) * (r(p * 2) - l(p * 2) + 1);
		sum(p * 2 + 1) += add(p) * (r(p * 2 + 1) - l (p * 2 + 1) + 1);
		add(p * 2) += add(p);
		add(p * 2 + 1) += add(p);
		add(p) = 0;
	}
}

void change(int w, int l, int r, int d){
	if(l <= l(w) && r(w) <= r){
		sum(w) += d * (r(w) - l(w) + 1);
		add(w) += d;
		return;
	}
	spread(w);
	int mid = (l(w) + r(w)) / 2;
	if(l <= mid) change(w * 2, l, r, d);
	if(mid < r) change(w * 2 + 1, l, r, d);
	sum(w) = sum(w * 2) + sum(w * 2 + 1);
}

int query(int w, int l, int r){
	if(l <= l(w) && r(w) <= r) return sum(w);
	spread(w);
	int mid = (l(w) + r(w)) / 2;
	int val = 0;
	if(l <= mid) val += query(w * 2, l, r);
	if(mid < r) val += query(w * 2 + 1, l, r);
	return val;
}

signed main(){
	scanf("%d%d", &n, &m);
	for(int i = 1; i <= n; ++i) scanf("%d", &a[i]);
	build(1, 1, n);
	for(int i = 1; i <= m; ++i){
		scanf("%d", &op);
		if(op == 1){
			scanf("%d%d%d", &l, &r, &d);
			change(1, l, r, d);
		}
		else{
			scanf("%d%d", &l, &r);
			printf("%lld\n", query(1, l, r));
		}
	}
	return 0;
}
```
